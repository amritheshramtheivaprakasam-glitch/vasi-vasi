    Help — how to use Vasi Vasi

    Vasi Vasi reads any text aloud using the voices already installed on your device. Everything works offline; nothing is sent anywhere.

    Keyboard shortcuts (while reading)

    SpacePlay / Pause
    ← / →Previous / next sentence
    Shift + ← / →Previous / next paragraph
    ↑ / ↓Faster / slower
    Home / EndFirst / last sentence
    EscBack to library
    ?Open this help

    Tips

    • Import PDF, DOCX, EPUB, plain text, or a web article — everything is processed on your device.
    • Click any sentence in the document to start reading from there.
    • The current sentence is highlighted, and each word lights up as it is spoken (in supported browsers).
    • Voices come from your device. On Windows and Android you can add Tamil voices in system settings.
    • Your reading position is saved automatically, so you can stop and continue later.
    • Install Vasi Vasi from your browser menu (“Add to home screen” / “Install”) to use it like a regular app, fully offline.

    Import from a web address

    The article text is read by your browser and stays on your device. Some websites block direct browser access — if that happens, copy the article text and use Add text instead.
